المرحلة A — استبدال الملفات على GitHub
----------------------------------------
1) فك ضغط الحزمة
   كليك يمين على ملف ramp-notes-v3.0.0.zip → «Extract All / استخراج الكل» → Extract. هيتفتح فولدر فيه 8 ملفات جاهزة.
2) ادخل على مستودعك
   افتح github.com وسجّل دخول → صورتك فوق → «Your repositories» → دوس على مستودع التطبيق بتاعك.
3) Add file → Upload files
   من صفحة المستودع — وانت في فرع main والمجلد الرئيسي اللي فيه index.html — دوس زر «Add file» وبعدين «Upload files».
4) اسحب الملفات وأفلتها
   اسحب من فولدر الحزمة وأفلت في الصفحة: index.html + sw.js + manifest.webmanifest — والأيقونات الثلاثة و.nojekyll لو عايز توحّد كل حاجة. نفس الأسماء بتستبدل القديم تلقائيًا.
5) Commit changes
   تحت في الصفحة اكتب رسالة v3.0.0 ودوس الزر الأخضر «Commit changes». كده الاستبدال تم ✔
ملحوظة: بديل لو شغال من الموبايل بس: افتح الملف في المستودع → أيقونة القلم ✏️ (Edit) → امسح المحتوى كله والصق محتوى الملف الجديد (افتحه من الفولدر بأي محرر نصوص وانسخ الكل) → Commit changes. كرّر لكل ملف من الثلاثة.

المرحلة B — الوصول للرابط (GitHub Pages)
----------------------------------------
1) Settings → Pages
   من تبويبات المستودع فوق دوس «Settings»، ومن القائمة الجانبية اختار «Pages».
2) فعّل النشر
   تحت Build and deployment: اختار Source = «Deploy from a branch»، وBranch = main والمجلد /(root) ثم «Save». لو متفعلة قبل كده سيبها زي ما هي.
3) خُد الرابط
   بعد دقيقة تقريبًا هيظهر شريط: «Your site is live at https://USERNAME.github.io/REPO/» — ده رابط تطبيقك. اكتب اسم حسابك والمستودع في قسم «الرابط» فوق وهيتحسبلك فورًا مع QR، وافتحه على الكمبيوتر الأول للتجربة.

المرحلة C — التثبيت على الموبايل
----------------------------------------
1) افتح الرابط على الموبايل
   أسهل حاجة: وجّه كاميرا الموبايل على الـQR اللي فوق. أو ابعت الرابط لنفسك في واتساب وافتحه. أندرويد: Chrome — آيفون: Safari.
2) تثبيت أندرويد
   هتظهر لافتة «تثبيت التطبيق» تحت — دوسها. أو قائمة ⋮ → «تثبيت التطبيق / Add to Home screen» → Install.
3) تثبيت آيفون
   زر المشاركة (مربع بسهم طالع) → «Add to Home Screen / إضافة إلى الشاشة الرئيسية» → Add.
4) أول فتحة من الأيقونة
   افتح التطبيق من الأيقونة الجديدة — هيفتح ملء الشاشة زي التطبيقات العادية، ويشتغل بدون إنترنت بعد أول فتحة، وبياناتك القديمة بتترحّل لوحدها.

المرحلة D — بعد كده — التحديثات
----------------------------------------
1) أي نسخة جديدة
   كرّر نفس خطوات الرفع (A). التطبيق المثبت هتطلعله لافتة «يتوفر تحديث — تحديث الآن» جواه — دوسة واحدة وخلصنا، من غير مسح كاش.

استكشاف الأخطاء:
لو النسخة القديمة لسه بتظهر بعد الرفع: اقفل التطبيق وافتحه تاني مع إنترنت واستنى دقيقة. لو استمرت: Chrome على الكمبيوتر → افتح الرابط → F12 → Application → Service Workers → Unregister ثم حدّث الصفحة. وعلى الموبايل: إعدادات Chrome → إعدادات المواقع → التخزين → امسح بيانات الموقع وافتح الرابط من جديد.

ملاحظة: بيانات التطبيق محفوظة على جهاز الموبايل فقط (localStorage) — صدّر نسخة احتياطية JSON من إعدادات التطبيق من وقت للتاني.
